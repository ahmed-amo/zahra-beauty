1. Présentation

BéBé Dome est une boutique e-commerce dédiée aux produits pour bébés. L’application est construite en Laravel + React + Inertia (expérience fluide sans API REST séparée pour le front boutique).

Objectifs : catalogue hiérarchique, panier / wishlist / COD, packs & listes de naissance partageables, espaces Admin / Client, multilingue FR / EN / AR (RTL).

3. Boutique

3.1 Accueil

Cover → marques → promotions → produits → packs → bannière → catégories → confiance / livraison.

3.2 Navigation

  • /products — catalogue
  • /categories, /category/{slug} — arbre de catégories
  • /product/{slug} — fiche (variants, galerie, avis)
  • /search — recherche

3.3 Panier & checkout

  • Panier / wishlist côté client
  • Checkout invité possible
  • Paiement live : cash on delivery
  • Chargily : prévu, non intégré

4. Packs & listes de naissance

Fonctionnalité majeure livrée pour le projet.

4.1 Packs admin

  • CRUD /admin/birth-list-packs
  • Types : Nouveau-né / Bébé / Bambin
  • Vitrine /listes-de-naissance + homepage
  • Clone pack → liste personnelle client

4.2 Listes client

  • Création / édition (nom, photo de couverture validée JPG/PNG/WEBP/GIF)
  • Ajout produits depuis le catalogue
  • Partage /liste/{token} — réserver, offrir, cagnotte

4.3 Bouton « Ajouter à la liste »

Icône cadeau sur toutes les cartes produit + fiche produit.

Navbar : libellé Packs And Lists (FR : Packs et listes).

5. Auth & emails

  • Register / login + OAuth Google / Facebook
  • Après Google (client) → accueil boutique
  • Pas d’OTP après Google (email déjà vérifié)
  • WelcomeEmail à la création de compte
  • Dev : Mailtrap sandbox (inbox Mailtrap, pas Gmail)
  • Confirmation commande + facture PDF

6. Tableaux de bord

Admin

Stats, catégories (arbre), attributs, produits, packs, promotions, hero/marques, commandes, clients, notifications.

Client

Dashboard, commandes, listes de naissance, wishlist, profil.

7. Déploiement Railway

  1. Image Docker production
  2. Variables d’environnement (APP_KEY, APP_URL, DB, MAIL_*, OAuth…)
  3. Volume : /var/www/html/storage/app/public
  4. Port public = $PORT (Nginx), healthcheck /up

Sans volume, les images admin disparaissent à chaque redeploy.

8. Installation locale

docker compose up -d db → Composer → migrate --seed → npm run dev + php artisan serve
